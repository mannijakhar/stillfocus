# Using Still Focus

## Start a session

Enter an optional session title, activity label such as Study or Work, and a note. Choose a preset or a custom duration from 1–240 minutes. Select **Begin focus**. The main window changes to a small floating timer.

## Floating timer

- Drag the bubble to move it.
- Click to open details; use the compact-view button to return to the bubble.
- Right-click for Pause/Resume, Open details, Hide, or End and save.
- The small minus button hides it while focus continues.
- Pause hides it and stops counting. Resume from the menu bar restores it.
- It stays on its current desktop instead of following all Spaces.

The menu bar offers Show Still Focus, Show floating timer, Hide timer, Start / Pause, View summary and Quit. Command-Q saves and quits. The main window's red button is intended to save and quit; amber minimises to the Dock.

## Labels and notes

At completion or when ending early, use the details editor to record what you did. Existing sessions can be edited from **Your rhythm**. Keep activity names consistent; labels differing only in case are grouped together in reports.

## Reports

Choose Day or Week, then use arrows for previous periods. Reports show focused time, sessions, time by activity, and focus intervals. Weekly reports include daily bars. CSV export writes all history, one row per uninterrupted focus interval, with UTC start/end timestamps and notes. Reports use local dates and calendar settings.

## What counts as focus

Only running timer time counts; pauses and breaks are excluded. Sleep and quitting pause the timer. On reopening, an unfinished session is paused. Intervals crossing midnight are split between days in reports. The app measures timer usage, not attention, keystrokes, or actual output.

History is saved about every five seconds while running and on state changes. A crash can lose the most recent unsaved seconds. The completion sound depends on the Mac's sound settings.

When the app detects a new day/week, it prepares the previous period's summary. A deliberately hidden window stays hidden. There are no scheduled reports while the app is closed.

This version does not toggle macOS Focus/Do Not Disturb and does not provide breaks, phone apps, cloud sync, login-at-startup, or automatic app updates.
