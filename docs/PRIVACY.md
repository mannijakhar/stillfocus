# Privacy

Still Focus stores session titles, activity labels, notes, focus intervals, duration settings and unfinished-session state locally at:

`~/Library/Application Support/StillFocus/history.json`

This version has no app account, telemetry, analytics SDK, advertising, or network sync. GitHub hosts the source and distribution files; personal focus history is not sent to GitHub by the app.

CSV exports contain session titles, notes, labels and timestamps. Treat them as personal data and share them intentionally. The local JSON history is not separately encrypted by the app; it relies on your Mac's account and storage protections.

Uninstalling the app does not delete history. To remove history, quit the app first, back up what you need, and remove the StillFocus application-support folder yourself.
